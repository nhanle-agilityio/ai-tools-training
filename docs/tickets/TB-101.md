# TB-101 — Last page of the task list cannot be opened

- **Type:** Bug
- **Priority:** High
- **Reporter:** Mobile team (PM)
- **Environment:** seed data (`make seed`)

## Description

The mobile app paginates the "Mobile App" project's tasks, 10 per page. The project has 23 tasks, but users can only see 20 of them. Scrolling down to load more shows an error and nothing else loads.

## Steps to reproduce

1. `make seed`, then `make run`
2. `GET /tasks?project_id=1&per_page=10&page=1` → inspect `pagination`
3. `GET /tasks?project_id=1&per_page=10&page=3`

## Expected result

- `pagination.pages` = 3, and `has_next` = `true` on page 2
- Page 3 returns the remaining 3 tasks

## Actual result

- `pages` = 2, `has_next` = `false` on page 2
- Page 3 returns `400 page 3 is out of range`

## Acceptance criteria

- [ ] Every task is reachable through pagination, for any `per_page` value
- [ ] An empty list still returns a valid page 1 (no error)
- [ ] A test covers a total that is not a multiple of `per_page`
