# TB-102 — Task search returns nothing when typing in lowercase

- **Type:** Bug
- **Priority:** Medium
- **Reporter:** QA

## Description

Searching for "login" does not return "Fix Login crash on Android 14" or "Login with Google". Users only see them when typing "Login" with a capital L. Nobody types with exact casing.

## Steps to reproduce

1. `make seed`
2. `GET /tasks?q=login&per_page=50`
3. `GET /tasks?q=Login&per_page=50`

## Expected result

Both requests return the same set: every task whose title or description contains "login", case-insensitively.

## Actual result

The two requests return different sets.

## Acceptance criteria

- [ ] Search is case-insensitive (at least for ASCII characters)
- [ ] Search still matches both title and description
- [ ] Tests are added
- [ ] (Discuss in the MR) Should non-ASCII (accented) characters also match regardless of case? If not handled, document the limitation.
