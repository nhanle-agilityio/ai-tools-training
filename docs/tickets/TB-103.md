# TB-103 — Tasks due today are reported as overdue

- **Type:** Bug
- **Priority:** High
- **Reporter:** Customer (via support)

## Description

A task whose `due_date` is today shows up in the "Overdue" list with `is_overdue: true`, even though the day is not over yet. Customers receive incorrect overdue reminders and are annoyed.

## Steps to reproduce

1. `make seed` (the seed data includes tasks due today, e.g. "Session expires too early")
2. `GET /tasks/overdue`

## Expected result

Only tasks with a `due_date` **before** today (and not `done`) are overdue.

## Actual result

Tasks due today are included in the overdue list.

## Acceptance criteria

- [ ] Task due today: `is_overdue = false`
- [ ] Task due yesterday: `is_overdue = true`
- [ ] Tests do not depend on the time of day they run (must pass at 00:01 and at 23:59)
