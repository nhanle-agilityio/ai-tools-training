# TB-105 — Changing a task's status wipes all its tags

- **Type:** Bug
- **Priority:** Critical (user data loss)
- **Reporter:** Multiple users

## Description

On the board, dragging a task from "To do" to "Done" sends `PATCH /tasks/<id>` with body `{"status": "done"}`. Afterwards, all of the task's tags are gone.

## Steps to reproduce

1. `make seed`
2. `GET /tasks/1` → the task has tags `["android", "bug"]`
3. `PATCH /tasks/1` with body `{"status": "done"}`
4. `GET /tasks/1`

## Expected result

Status becomes `done`, and tags stay `["android", "bug"]`.

## Actual result

`tags: []`

## Acceptance criteria

- [ ] PATCH only changes the fields present in the body
- [ ] Explicitly sending `"tags": []` still clears all tags
- [ ] Tests cover both cases
- [ ] (Bonus) Check whether other PATCH fields have a similar problem
